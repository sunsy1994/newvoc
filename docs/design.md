# AutoVOC 页面设计规范

本文档是 AutoVOC 后续业务页面的统一视觉基准。新增页面优先沿用这里的布局、色彩和组件语气，避免每个模块重新发明一套界面。

## 设计方向

- 风格关键词：macOS / Linear / Notion / Nexus SaaS，轻量、低对比、清爽卡片式后台。
- 页面对象：管理员、VOC 分析师、业务看板使用者。页面应偏工作台，不做营销落地页。
- 数据原则：业务页面只展示已有接口和真实数据；缺少底表或指标时显示空状态，不使用 mock 数据。

## 色彩

- 主色：`#5347CE`
- 辅助紫：`#887CFD`
- 辅助蓝：`#4896FE`
- 辅助青：`#16C8C7`
- 页面背景：`#F5F7FB`
- 卡片边框：`#E8ECF3`
- 主文字：`#151720`
- 次级文字：`#7B8190`

使用方式：

- 主操作按钮使用 `#5347CE`，可带轻微紫色阴影。
- 图表序列优先使用紫、蓝、青，不做大面积渐变背景。
- 状态标签用浅底深字，例如 `#F0EFFF` + `#5347CE`。

## 布局

- 使用双栏 Sidebar：左侧一级菜单深色胶囊选中态，右侧二级菜单白色胶囊选中态。
- 页面主体背景保持浅灰，内容区域使用白色圆角卡片承载。
- 常规页面间距：外层 `space-y-5`，卡片内边距 `p-5`。
- 看板类页面优先 2 列或 3 列网格，操作维护类页面优先“操作卡片 + 数据表格”。

## 组件

- 卡片：`rounded-2xl border border-[#e8ecf3] bg-white shadow-[0_10px_28px_rgba(26,32,44,0.04)]`。
- 按钮：高度 36-40px，圆角 8-10px；图标使用 `lucide-react`，不要手写 SVG。
- 输入框/选择框：浅灰底 `#F7F9FC`，边框 `#E8ECF3`，聚焦态使用主色描边。
- 表格：表头浅灰底、小字号、低对比；长文本截断；横向溢出用容器滚动。
- 空状态：白色卡片或虚线卡片，短句说明即可，不放大段教程。

## 页面语气

- 标题短而业务化，例如“市场看板”“KOL画像”“评论用户画像”。
- 操作说明只保留必要标签，不在页面里解释系统能力、快捷键或实现逻辑。
- 管理员页面允许出现“导出样本”“上传结果”“批次筛选”等工作流文案。

## 实现约束

- Next.js App Router + TypeScript + Tailwind CSS。
- 导航数据统一来自 `src/config/navigation.ts`。
- 优先小组件，不引入复杂状态管理。
- 新增页面开发完成后至少运行 `npm run typecheck` 和 `npm run build`；涉及后端接口时同时运行 Python 测试。
