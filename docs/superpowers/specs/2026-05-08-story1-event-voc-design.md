# 故事线1：事件驱动的 VOC 精准营销资产系统

## 1. 产品定位

故事线1不做一次性的舆情复盘，而是把每一次品牌/车型营销事件、产品舆情事件，沉淀成可复用的 VOC 资产。

系统以“事件”为锚点，串联内容、评论、作者、KOL/KOC、用户心智和用户阶段，最终回答：

- 这次事件发生了什么，传播和舆情态势如何？
- 用户到底记住了什么、质疑什么、表达了什么意向？
- 哪些内容和 KOL/KOC 带来了有效兴趣，哪些只是热闹或风险？
- 下一次类似车型、类似卖点、类似事件，应该投什么样的 KOL/KOC，面向什么样的用户？

核心闭环：

事件输入 -> 内容聚合 -> 评论打标 -> 用户心智/阶段识别 -> KOL受众画像 -> 精准投放建议 -> 资产沉淀

## 2. 首期事件范围

首期只覆盖两类事件。

### 2.1 品牌/车型营销事件

示例：

- 新车上市
- 发布会
- 试驾会
- 权益政策发布
- 节日 campaign
- 区域营销活动

核心业务问题：

- 这次传播有没有打到目标人群？
- 用户有没有记住官方想传达的卖点？
- 哪些平台、内容、KOL/KOC 带来了有效兴趣？
- 哪些表达方式可以复用到下一次投放？

重点输出：

- 传播热度与平台结构
- 主命题与用户记忆点
- 官方主张拉通率
- 内容/KOL有效互动率
- 目标心智用户匹配度
- 后续投放建议

### 2.2 产品舆情事件

示例：

- 价格争议
- 配置争议
- 质量反馈
- 功能槽点
- 车机、智驾、续航、空间、售后等集中反馈

核心业务问题：

- 这个问题是真风险，还是局部噪音？
- 讨论来自真实车主、试驾用户、准车主，还是泛用户？
- 用户反馈是否有证据支撑？
- 哪些问题需要产品/售后/公关优先响应？

重点输出：

- 负面扩散趋势
- 证据强度
- 车相关作者/评论样本
- 产品、公关、售后响应建议

### 3.6 关系视图：解释影响路径

关系视图不是装饰性图表，而是解释“事件如何被内容承载、内容如何吸引用户、KOL如何影响人群”。

首期建议保留三张图：

- 事件传播图：事件 -> 内容 -> 发声主体
- KOL受众图：KOL -> 内容 -> 评论者心智/阶段
- 内容人群图：内容 -> 评论者阶段 -> 意向表达

核心用途：

- 找关键内容节点
- 找关键发声主体
- 看某个 KOL 吸引了什么用户
- 看某类内容是否更容易触发目标意向

## 4. 两类事件的分析口径差异

### 4.1 营销事件分析口径

营销事件优先回答“传播是否有效”。

核心指标：

- 热度：内容量、评论量、互动量
- 增速：24h/72h 增长率、峰值出现点
- 平台结构：不同平台贡献的内容、评论和互动
- 来源结构：官方、媒体、KOL、KOC、普通用户占比
- 命题占比：用户讨论的主命题 Top
- 记忆点强度：高频复述的卖点、短句和观点
- 官方主张拉通率：用户是否复述或接受官方想传递的卖点
- 主张偏移率：用户是否误解、反向理解或跑偏
- 有效互动率：探讨与车相关的评论数 / 评论总数
- 目标人群匹配度：评论者心智/阶段与目标人群是否匹配
- 误伤率：内容引发误解、争议或负向放大的比例

### 4.2 产品舆情事件分析口径

产品舆情事件优先回答“问题是否真实、是否需要响应”。

核心指标：

- 负面率：负向评论占比
- 质疑率：质疑/不信任/担忧表达占比
- 证据强度：亲历、试驾、截图、视频、复现条件等证据类型
- 扩散速度：负面问题在不同平台和内容间的扩散速度
- 关键节点：引发扩散的内容、KOL、作者
- 业务归因：产品、价格、服务、销售、传播误解、竞品对比
- 建议动作：解释、澄清、补证据、产品优化、售后跟进、公关响应

## 6. 标签体系与标注优先级

### 6.1 事件标签

首期标签：

- 事件类型：营销事件、产品舆情事件
- 事件状态：进行中、已结束、归档
- 主命题 Top
- 关联品牌
- 关联车型

### 6.2 内容标签

首期必须标注：

- 内容类型：上市信息、测评、对比、提车、试驾、体验、投诉、促销、观点、新闻搬运
- 内容角色：种草型、解释型、测评型、对比型、证据型、争议型、促销型
- 命题标签：价格价值、智能科技、空间实用、家庭出行、续航能耗、安全性能、品牌信任、售后服务等
- 问题标签：价格贵、配置低、车机卡顿、续航焦虑、智驾质疑、空间不够、服务差等
- 证据标签：亲历描述、试驾体验、截图证据、视频证据、参数对比、转述
- 风险标签：误解放大、价格争议、质量风险、竞品攻击、情绪化扩散

### 6.3 评论标签

首期必须标注：

- 情绪标签：正向、中性、负向
- 态度标签：认可、质疑、观望、反对、求证、咨询
- 阶段标签：知晓、兴趣了解、对比、试驾/到店、报价、下订、车主/售后、未知
- 心智标签：价格敏感型、技术参数导向型、家庭出行型、颜值设计型、品牌信任型、实用理性型、竞品对比型、服务体验型
- 意向标签：想了解、问价格、问配置、想试驾、想购买、等优惠、放弃、已购买、售后反馈
- 命题标签：同内容命题体系
- 问题标签：同内容问题体系
- 证据标签：亲历、试驾、截图、视频、朋友转述、无证据情绪
- 置信度：高、中、低
- 打标原因：命中关键词、语义判断、上下文推断、规则命中

### 6.4 作者/KOL标签

首期必须标注：

- 作者类型：KOL、KOC、普通用户、媒体、品牌号、经销商号
- 阶段标签：车主、试驾、准车主、泛用户、未知
- KOL领域：汽车、科技、生活方式、财经、区域本地、综合
- 传播角色：种草型、解释型、测评型、对比型、争议放大型、高证据型、高意向触发型、风险型
- 证据价值：高证据、中证据、低证据
- 风险价值：高风险、中风险、低风险
- 目标受众心智 Top
- 目标受众阶段 Top

## 8. 建议的数据清洗和标注流程

### 8.1 清洗流程

1. 建事件配置表，先人工定义事件名称、类型、品牌、车型、时间范围和关键词包。
2. 清洗内容数据，统一平台、URL、发布时间、作者、互动量。
3. 用关键词、车型、品牌、时间窗口和语义匹配，把内容归因到事件。
4. 清洗评论数据，建立评论到内容、内容到事件的链路。
5. 清洗账号数据，把内容作者和评论作者统一进入账号池。
6. 生成内容、评论、作者的基础统计。

### 8.2 标注流程

1. 先标内容类型和内容命题，明确每条内容在说什么。
2. 再标评论情绪、态度、阶段、心智、意向，明确用户在表达什么。
3. 再聚合到内容，计算内容的评论结构和价值标签。
4. 再聚合到 KOL，计算每个 KOL 吸引的人群结构和车相关有效互动率。
5. 最后聚合到事件，形成事件复盘和精准营销建议。

### 8.3 人工校验重点

优先人工校验这些样本：

- 高互动内容
- 高负面内容
- 高争议内容
- 高意向评论
- 车主/试驾评论
- 关键KOL内容
- 模型低置信但业务重要的评论

## 10. 当前最小闭环

如果只做一个最小可用版本，建议闭环如下：

1. 人工创建一个事件。
2. 导入该事件相关内容和评论。
3. 清洗内容、评论、作者。
4. 标注内容类型、评论情绪、评论阶段、评论心智、评论意向。
5. 生成内容库、评论库、KOL库三个页面。
6. 输出一页事件复盘：这次事件影响了谁、哪些内容有效、哪些 KOL/KOC 值得复用。

这个版本就已经能证明故事线1的核心价值：不是看一次舆情，而是把一次事件沉淀成下一次精准营销的资产。
