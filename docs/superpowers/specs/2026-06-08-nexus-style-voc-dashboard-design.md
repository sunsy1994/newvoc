# Nexus风格 VOC市场看板视觉改版设计

## 目标

把 `VOC看事件 / 市场看板` 从当前普通卡片后台，调整为参考 Dribbble「Nexus Saas Marketing Dashboard」的轻量 SaaS 数据后台风格。改版只触及前端视觉和布局，不改变后端接口、ETL口径和真实数据约束。

## 参考风格

用户提供的参考色：

- 主紫：`#5347CE`
- 辅紫：`#887CFD`
- 数据蓝：`#4896FE`
- 青绿：`#16C8C7`

参考页面特征：

- 大面积浅灰白背景。
- 左侧白色导航栏，选中态轻、克制。
- 主内容区域卡片较规整，圆角约 14-18px。
- 卡片边框淡、阴影轻，整体低对比度但精致。
- 指标卡包含小图标、标题、大数字、轻量状态标签。
- 图表颜色清新，紫、蓝、青绿组合明显。
- 页面信息密度适中，不做夸张装饰。

## 应用边界

- 保留现有双栏导航结构，但视觉调整为更接近 Nexus 的白底侧栏。
- 保留现有真实数据接口：`/api/voc/events/{event_id}/market-dashboard`。
- 保留现有页面模块：事件筛选、声量总览、趋势、KOL类型、渠道、热门帖子。
- 不新增 mock 数据。
- 不新增图表库，继续使用轻量 SVG/CSS 图表。
- 不做 AI摘要。

## 视觉规则

- 页面背景：`#F5F7FB` 附近的冷灰白。
- 主内容卡片：白色背景，`#E8ECF3` 级别淡边框，轻阴影。
- 品牌色主要用于选中态、图表主线、指标点缀，不铺满页面。
- 主按钮使用 `#5347CE`，hover 可用更深紫色。
- 增长/评论相关辅助色使用 `#16C8C7`。
- 图表配色：
  - 总声量：`#5347CE`
  - 主贴：`#4896FE`
  - 评论：`#16C8C7`
  - 辅助紫：`#887CFD`
- 圆角控制：
  - 页面容器：20px 左右。
  - 普通卡片：16px。
  - 小标签/按钮：10-999px。

## 页面布局

顶部区域：

- 左侧显示 `Dashboard` / `市场看板`。
- 右侧放事件选择器和查看按钮。
- 事件状态、品牌、车型、类型以轻量标签显示。

指标卡：

- 5 张卡片横向排列。
- 每张卡片包含图标、指标名、主数字、说明标签。
- KOL发声卡显示 `N 位`，说明为 `贡献 M 条主贴`。

图表区：

- 第一行：声量趋势大卡 + KOL类型分布卡。
- 第二行：渠道分布卡 + 热门帖子榜卡。
- 图表卡头部包含标题和简短口径说明。

热门帖子榜：

- 保持轻量，只显示排名、帖子名称、总互动量。
- 视觉接近列表卡，不做重表格。

## 验收标准

- 页面整体明显更接近 Nexus SaaS 后台风格。
- 颜色使用用户提供的四个主色。
- `npm run typecheck` 通过。
- `npm run build` 通过。
- 市场看板仍能通过真实接口渲染数据。
