# 竞品作品解读 Markdown 模板设计

## 范围

本次只完善竞品作品库“维护解读”弹窗和竞品报告的 Markdown 解析，不增加新的报告分析维度。

## 编辑行为

- 打开已有解读的作品：原样加载已保存 Markdown，不覆盖内容。
- 打开未维护解读的作品：编辑框直接预填固定模板。
- 不增加“插入模板”按钮。
- 模板只是前端草稿；用户点击“保存解读”前不写入数据库，也不改变列表中的“未维护”状态。
- 点击“清空解读”：删除数据库内容，编辑框恢复为未保存的固定模板，列表状态变为“未维护”。
- 模板上方显示提示：“报告按以下六个固定标题读取内容，请勿修改标题名称。”

## 固定模板

```md
## 视频介绍
- 视频主要讲述什么
- 核心场景与目标受众
- 主要产品或车型信息

## 要点总结
- 00:00 开场内容
- 00:15 核心卖点
- 00:35 用户场景
- 00:50 行动引导

## 评论情绪
- 正面：用户认可的内容
- 中性：用户讨论但态度不明确的内容
- 负面：用户质疑或不满的内容

## 评论关键词
- 关键词一
- 关键词二
- 关键词三

## 典型评论
- 典型评论原文一
- 典型评论原文二
- 典型评论原文三

## 作者回复
- 作者主要回复内容
- 回复采用的沟通方式
- 未回复时填写：无
```

## 报告解析

- 只识别六个二级标题：视频介绍、要点总结、评论情绪、评论关键词、典型评论、作者回复。
- 评论情绪按 `正面：`、`中性：`、`负面：` 分别解析。
- 缺失某个情绪项时，该项显示“未标注”。
- 普通列表项去掉开头的 `-` 后写入报告。
- 不执行 Markdown 中的 HTML 或脚本。
- 已有旧内容继续兼容；未按三种情绪格式填写时，保留原有文字作为正面摘要，避免历史数据丢失。

## 验收标准

- 未维护作品打开后可直接在完整模板中填写。
- 已维护作品不会被模板覆盖。
- 模板未保存时仍显示“未维护”。
- 清空后数据库内容为空，编辑框恢复模板草稿。
- 报告正确展示三种评论情绪。
- 竞品库接口、报告渲染、前端类型检查和生产构建通过。
