# AI 报告摘要共享视觉与颜色规范

## 使用范围

本规范用于市场部、产品部、销售部 AI 报告的摘要模式。产品部首先落地；市场部和销售部在各自故事线确认后复用。

共享的是视觉骨架与颜色体系，不是业务章节和文案模板。

## 设计来源

参考主页 AI 对话框的柔和 AI 氛围，并收敛为企业报告可长期阅读的表达：白色内容面、主题色轻渐变、低透明度光晕、清晰深色文字。

## 颜色原则

- 页面只使用一套主题色体系，不为不同章节分配独立色相。
- 主题色直接复用系统变量，不新增硬编码品牌色。
- 大面积区域保持白色或系统浅色面板。
- 渐变只用于顶部结论卡和极少数强调元素。
- 状态差异优先通过标题、标签文字、图标和明度表达。
- 惊喜、机会、风险不得分别铺设大面积绿、蓝、红背景。
- 负向含义只有在数据图表确实需要情绪编码时才使用既有负向色；摘要叙事层不使用警报式红色装饰。

## 设计令牌

| 用途 | 令牌 |
| --- | --- |
| 主色 | `var(--theme-primary)` |
| 辅助主题文字 | `var(--theme-selected-text)` |
| 浅主题底色 | `var(--theme-selected-bg)` |
| 柔和面板 | `var(--theme-soft-panel)` |
| 标题文字 | `var(--theme-ink)` |
| 正文文字 | `var(--theme-body)` |
| 次要文字 | `var(--theme-muted)` |
| 边框 | `var(--theme-border)` |
| 内容面 | `var(--theme-white)` |

允许通过 CSS 透明度使用主题色，但不为摘要组件增加新的 RGB 常量。

## 共享组件外观

### 顶部结论卡

- 白色内容面叠加从 `theme-selected-bg` 到白色的极浅渐变。
- 只允许一个低透明度主题色径向光晕。
- 标题使用 `theme-ink`，导语使用 `theme-body`。
- 关键指标胶囊使用浅主题底色和主题色文字。

### 纵向故事线

- 序号、连接线和小型章节标签统一使用主题色。
- 章节主体使用白底，不使用不同颜色区分章节。
- 当前重点章节可使用浅主题色边框或底色，不改变色相。

### 指标胶囊

- 数字使用深色正文或主题色。
- 标签使用次要文字色。
- 不用红绿颜色暗示业务好坏，除非指标定义本身具有固定正负语义。

### 证据卡

- 使用柔和面板底色和统一边框。
- 引号或证据标记使用主题色。
- 评论正文保持深色，来源信息使用次要文字色。

## 布局骨架

三个部门统一使用：

1. 顶部一句话结论卡。
2. 下方纵向故事章节。
3. 每章由结论、解释、真实指标和可选证据组成。
4. 宽屏采用“正文 + 侧栏指标/证据”，窄屏改为单列。

各部门自行定义章节数量与业务含义，不要求章节标题完全一致。

## 禁止项

- 彩虹渐变。
- 每章一个颜色。
- 高饱和大色块。
- 用颜色代替文字含义。
- 在摘要中复制完整图表。
- 在组件内硬编码与系统主题无关的品牌色。

## 后续接入顺序

1. 产品部：关注、态度、竞品对比、证据。
2. 市场部：传播节奏、话题、平台、反馈。
3. 销售部：线索漏斗、购买信号、用户意图、渠道。

每次接入前单独确认部门故事线，但颜色、布局基础组件和降级规则直接复用本规范。
